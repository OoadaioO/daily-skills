# 需求拆解规范


## 将需求拆解成以下几部分

- 页面流转
- 需求拆解表
- 估时汇总
- 估时假设
- 待确认项


## 拆解说明

### 页面流转

页面流转依赖页面路径地图，路径地图文件如果不存在，使用 `../references/self-hosting-ruting.yaml` generate-page-graph 拆解页面流转地图后再分析

- 以文本图示形式拆解页面流转
- 不同端的页面流转分开拆解

示范：

1. 小程序

```【积分中心其余入口】

  积分中心(tab 1.5d)
    ├─▶ 积分明细(1d) ·························· 叶子
    ├─▶ 积分规则说明(0.5d) ···················· 叶子
    ├─▶ 签到领积分(1d) ························ 叶子
    └─▶ 兑换记录(1d) ──▶ 兑换订单详情(1.5d 叶子)
```

2. 管理后台

```
【订单履约售后流】

  兑换订单列表(0.5d) 
        │
        └──▶ 积分流水查询(0.5d 叶子) 

```

### 需求拆解表

按照：`端、业务流、页面、页面功能、备注、估时` 将需求拆解成表格。估时按照不同端的评估方法进行估算。


示范：

```markdown
| 端 | 业务流 | 页面 | 页面功能 | 备注 | 估时 |
|---|---|---|---|---|---|
| 小程序 | 积分兑换 | 积分中心（tab） | 1. 可用积分展示（不含冻结/过期）<br/>2. 即将过期积分<br/> 3. 赚积分入口（去消费/去签到）<br/>4.兑换商品列表：全部/实物/优惠券/等级限制 4 个筛选 tab + 商品卡片（图/名称/积分价/现金补差/库存/兑换方式与等级标签）<br/>5.右上角快捷入口（明细/兑换记录/规则）<br/>6. 未登录引导 | PRD「我的积分+商城首页」合并口径；⚠即将过期模块原型缺失待确认；去消费跳商城既有链路 | 1.5 天 |
```


### 估时汇总

```markdown

| 小程序 · 积分资产查询（明细/规则） | 2 | 1.5 天 |

| **小程序小计** | **10** | **9 天** |

```
